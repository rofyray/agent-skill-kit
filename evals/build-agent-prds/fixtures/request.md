# Reading Shelf project conversation

Create a PRD for a small local-first browser app named Reading Shelf. It has a library view and a JSON import/export view. Users add a reading item with a title, HTTP(S) URL, and optional tags, mark it read/unread, filter by tag or read status, and retain changes after reload. Import validates the entire file before changing existing data; invalid files leave the library unchanged. Export and re-import must preserve IDs, tags, and read status. Use the sample's schema. No accounts, network sync, paid services, or deployment work are in scope.

The library UI and import/export feature should be able to progress in parallel once shared state and persistence contracts are agreed. Include task commits and feature branches. Define the application behavior at integration, not just unit tests. Target current desktop Chrome and Firefox, with keyboard-usable controls. There is no repository yet; propose a minimal implementation setup and identify commands that must be established rather than claiming they already exist.

The attached normalize-tags.js was accepted in our earlier discussion. Reuse it unchanged unless you identify a necessary correction, in which case explain the correction. sample-library.json is our illustrative test data, not production data. approved-mark.svg is the chosen product mark; obsolete-mark.svg is an abandoned draft. Preserve the useful material so another coding agent can build without this conversation. Deliver a ZIP with a compact driver and supporting files, and explain where to start after extraction. Write the PRD, not the application.
