# Troubleshooting

Treat each cause below as a hypothesis to investigate. Preserve accepted work and isolate the failing layer before changing providers or rerendering media.

## Media production and processing

| Symptom | Check | Focused response |
| --- | --- | --- |
| Brand, product, or lettering changes | Reference roles and actual output | Keep exact elements in controlled layers; repair the affected image or region before animating. |
| Subject freezes unexpectedly | Contradictory movement and hold instructions | Distinguish travel, local motion, and the deliberate final hold. |
| Generated scene includes blank panels | How the safe text region was described | Describe a calm continuous scene region; adjust the composition before another paid attempt. |
| Ending drifts after a good arrival | Earlier tail frames and the actual media | Trim to the useful state if one exists, then update derivatives and beat mapping. |
| A join changes texture or silhouette | Both source boundary states | Move the seam, repair a segment, or test a controlled transition; matching coordinates alone is insufficient. |
| Concat or dissolve fails | Dimensions, cadence, pixel aspect, time base, timestamps, and actual durations | Normalize appropriately and recompute offsets; do not re-encode a broken assembled file repeatedly. |
| Smooth surfaces show bands | Processed gradients and color conversion | Adjust quality or processing; inspect the final output rather than only the source. |
| Submission timed out | Existing job ID and supported status | Check the submitted job before retrying to avoid duplicate charges. |
| Repeated generation failures | Whether the concept exceeds the tool or budget | Stop at the limit and change the treatment or provide a manual handoff. Do not assume rejected jobs were free. |

## Browser and scroll behavior

| Symptom | Check | Focused response |
| --- | --- | --- |
| Seeking fails or returns to the beginning | Metadata, seekable media, response behavior, codec support, and errors | Fix the actual loading/encoding issue; consider a bounded Blob route only when appropriate. |
| Seeking freezes | Same-time requests, busy flag, pending target, timeout, and error paths | Skip no-op seeks and recover all controller states; stop into a fallback if recovery fails. |
| Scrubbing feels rough | Decode cost, keyframe spacing, overlapping seeks, layout work | Measure first; coalesce requests, reduce repeated writes, or encode a smaller suitable candidate. |
| Loading ring never finishes | Response failure, missing size, stalled transfer, decode failure | Distinguish progress types; abort a real stall and expose the static path. |
| Video completes after the user disables motion | Request cancellation and stale callbacks | Abort unnecessary work and invalidate old callbacks so they cannot reenable media. |
| Hero is blank after resizing | CSS/controller policy and previous state cleanup | Recompute mode and geometry, reset stale states, and synchronize current progress. |
| Static layout downloads hidden video | Source assignment before mode selection | Delay URLs for unused media; ensure the static layout still loads its own intended image. |
| Captions disappear too quickly | Actual reading plateau and total page distance | Shorten or merge copy, alter pacing, or move content into regular flow. |
| Reduced motion stacks every caption | Final-state logic for overlapping bands | Render a separate static summary or ordered content sequence. |
| Direct file preview lacks motion | Fetch/module restrictions and preview context | Use an available local or platform preview; do not call the static path a verified scrub experience. |
| Screenshot misses a visible video frame | Browser visibility, compositor capture, and media readiness | Use a supported visible capture or alternate available browser tool; combine visual and state evidence and disclose capture limits. |

## Layout and interaction

| Symptom | Check | Focused response |
| --- | --- | --- |
| Entrance never plays | Cascade and initial enhancement state | Correct scoped states without making baseline content depend on a successful script. |
| Later card hovers lag | Persisting entrance delays and selector specificity | Retire the stagger before interactive states; test later siblings. |
| Dynamic style stops responding | Persisting keyframe values on the same element | Separate entrance and dynamic layers or explicitly release the completed animation. |
| Letter tails or focus rings clip | Reveal mask, line box, and overflow | Reserve appropriate breathing room and inspect real glyphs and focused controls. |
| Narrow page shifts sideways | Wide content, decorations, intrinsic sizing | Fix the offending geometry before hiding overflow. |
| Reduced motion moves an element off-screen | Structural transforms cleared with animated ones | Preserve breakpoint-specific layout transforms. |
| Demo form claims success | Whether data actually reaches an integration | Label the demo or implement the authorized real integration and truthful response states. |
| Copy changes during a build pass | Package/version and string ownership | Restore approved copy or record a deliberate requested revision. |

## Missing or failing tools

Identify whether the host lacks access, authentication, a required operation, or a functioning renderer. Do not infer successful connection from a user's "done" message; verify with an appropriate supported read. A running render with reported progress differs from a tool that never responds.

Use bounded retries appropriate to the tool and task. After repeated failure without progress, explain the blocked capability and continue independent work. Do not repeatedly restart applications, install dependencies, or switch paid providers without evidence and authorization. Keep a complete manual handoff when the unavailable capability is essential.
