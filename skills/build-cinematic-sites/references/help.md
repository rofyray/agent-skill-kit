# Build Cinematic Sites Help

Use this reference only for help mode. Present every mode, both examples per mode, and the guidance below without starting production. Modes are natural-language hints, not commands tied to a particular client.

## What this skill does

Turns a brief into a complete cinematic website: page structure, copy, visual identity, media, interactions, responsive layouts, and verification. It designs the visitor journey before producing footage. The result can use supplied photography, scroll-driven video, controlled graphics, restrained animation, or a static treatment.

It supports the user's existing framework, site builder, media tools, and project conventions. It finishes with the site and its preview or an accurately labeled production handoff when execution is unavailable. It does not manage hosting or publication.

## Modes

| Mode | Use it for | Receive |
| --- | --- | --- |
| `plan` | Compare directions or prepare a build before committing to production. | A recommendation, content structure, design package, media route, and acceptance criteria. |
| `build` | Create a complete site from a new brief or accepted plan. | The implemented site, assets, available preview, and verification report. |
| `revise` | Change an existing site, its copy, media, or motion. | A focused revision with checks for affected behavior. |
| `audit` | Review a package or site without changing it. | Prioritized findings, evidence, and practical fixes. |
| `help` | Learn how to use the skill. | This complete guide, without execution. |

## Start here

Describe the subject, intended visitor, and what the visitor should understand or do. Include existing files or platform details, brand assets, approved copy, and visual references when available. Mention locked decisions, budget or attempt limits for paid media, and whether you want planning or a finished build. You can give feedback in ordinary language such as "the opening feels slow" or "keep the footage but make the captions easier to read."

You do not need to pick a generator or know how to code. The skill checks what tools are actually available and uses suitable configured tools within your instructions. It does not automatically create accounts, install software, or assume buying this skill connects a service. With no generator, it can use existing media or controlled graphics. With no execution environment, it can return the design and implementation handoff, clearly marked as unverified.

Two optional companions can deepen the work:

- `design-beyond-defaults`: explore more distinctive directions, critique the interface, or polish it while preserving the brief.
- `ai-motion-graphics-direction`: direct product choreography, architecture, exact graphics, kinetic type, or explanatory media for the site.

Both are in [Agent Skill Kit](https://github.com/rofyray/agent-skill-kit). If one would help and is unavailable, point to its folder in that repository and the repository's installation instructions. Installing a skill is separate from connecting a media tool. Neither companion is required for ordinary site creation.

## Examples

| Mode | Simple starter | Additional realistic example |
| --- | --- | --- |
| `plan` | "Plan a cinematic landing page for my ceramic studio. I have product photos and want visitors to book a visit." | "Compare a photographic and a vector treatment for our existing product site. Preserve our logo and claims. Give me the design package before building or generating media." |
| `build` | "Build a one-page portfolio from these photographs with a quiet visual story and a clear contact link." | "Build the accepted product journey in our existing React project. Use my supplied clip, preserve the approved copy, and make the site complete with reduced motion or failed video loading." |
| `revise` | "Keep this site, but make its hero captions readable on a small screen." | "The film is approved. Fix the visible join, shorten the scroll journey, and retain the layout and form behavior. No new paid generation." |
| `audit` | "Review this site for motion, readability, and mobile problems. Do not change it." | "Audit the plan and actual preview for our architectural reveal. Check factual claims, crop safety, reduced motion, keyboard access, and whether the fallback preserves the story." |
| `help` | "help" | "What can this skill do, and how would I use the optional design and motion skills?" |

End by inviting the user to choose a mode or adapt an example. Ordinary "help me build" requests should proceed as work rather than display this guide.
