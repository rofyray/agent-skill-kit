Material Library

Twelve optional visual directions on the same two tasks. Compare the material choices, then derive your product’s layout from its own job. All data is fictional; no booking or network request is made. Fonts use local fallback stacks.

Try an empty submission, select a session, filter to “Blocked” for an empty queue, or use the keyboard to inspect focus. A selected queue row and its open-check count are shared comparison data.
