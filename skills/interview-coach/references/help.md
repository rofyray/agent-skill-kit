# Interview Coach Help

Use this reference to answer help mode. Present the explanation, mode catalog, start guidance, and examples in a detailed but scannable user-facing form. Include every named mode and both example columns; do not collapse mode groups or omit modes or examples for brevity. Do not read private coaching state or begin another workflow while answering help.

## What this skill does

This skill provides adaptive, evidence-based coaching across the interview and job-search lifecycle. It can establish a candidate profile, decode roles, improve application materials, build a reusable storybank, create company and interviewer prep, run drills and mocks, analyze transcripts, learn from feedback and outcomes, and coach compensation conversations.

It triages before prescribing: advice and drills change based on the candidate's timeline, target level, evidence, interview format, performance patterns, and live opportunities. When the user approves persistent state and the host can access files, it maintains a private bounded coaching workspace across sessions. State is optional; urgent prep and analysis still work without it.

## Modes

### Start and navigate

- `kickoff`: establish goals, timeline, profile, directness, and first plan.
- `status`: summarize the current pipeline, bottleneck, and recommended next move.
- `help`: display this guide without starting another workflow.

### Choose and understand roles

- `research`: investigate a company and role with current, sourced evidence.
- `decode`: analyze one or more job descriptions and assess fit.
- `concerns`: anticipate likely interviewer concerns and build honest counters.
- `questions`: prepare tailored questions for a specific stage or interviewer.

### Build application materials

- `resume`: audit, rewrite, or target a resume without inventing evidence.
- `linkedin`: improve LinkedIn positioning, discoverability, and consistency.
- `pitch`: create a positioning spine and context-specific introductions.
- `outreach`: draft networking, recruiter, referral, or follow-up messages.
- `apply`: draft truthful answers to application screening questions.

### Prepare and perform

- `stories`: build, improve, audit, and practice a reusable storybank.
- `prep`: create a company, role, round, and interviewer-specific prep brief.
- `present`: prepare a presentation, portfolio review, case, or take-home discussion.
- `practice`: run focused drills against the current bottleneck.
- `mock`: simulate a full interview one question at a time.
- `hype`: prepare an evidence-based day-of confidence and recovery plan.

### Learn and improve

- `debrief`: capture a fresh memory-only post-interview account without false precision.
- `analyze`: evaluate a transcript with format-aware evidence and scoring.
- `round`: combine fresh impressions, transcript analysis when available, and state updates.
- `feedback`: record external feedback, outcomes, corrections, or coaching feedback.
- `progress`: review trends, calibration, targeting, story health, and priorities.
- `reflect`: close or pause a search with a retrospective and retention choice.

### Close the loop

- `thankyou`: draft stage- and interviewer-specific follow-up notes.
- `salary`: prepare early and mid-process compensation conversations.
- `negotiate`: analyze an offer and build a truthful post-offer negotiation plan.

The user can name a mode or describe the outcome naturally. No slash command is required.

## Start here

If an interview is scheduled, provide the role, company, stage or format, date, and any job description or recruiter guidance. If no interview is scheduled, start with `kickoff`, `decode`, `resume`, or whichever outcome is most urgent. A resume and persistent state improve personalization but are never prerequisites for urgent help.

The skill will ask one high-value question at a time. Browsing, file persistence, app control, voice, and external sending depend on capabilities and permissions available in the active host. It never sends applications or messages, stores sensitive information, or acts on an offer without the required authorization.

| `concerns` | `What concerns might a hiring manager have about my move from agency to in-house work?` | `Rank the likely concerns for this director role and build honest evidence-based counters.` |
| `questions` | `Give me five questions for tomorrow's hiring-manager interview.` | `Tailor questions for this named people leader and keep them inside their verified lane.` |
| `resume` | `Audit my resume for this senior operations role and prioritize the top three fixes.` | `Rewrite these bullets from my confirmed story evidence without inflating ownership.` |
| `linkedin` | `Review my LinkedIn headline and About section for product-leadership searches.` | `Deep-audit my profile for discoverability, evidence, and consistency with my resume.` |
| `pitch` | `Build my 60-second tell-me-about-yourself answer from my resume and target role.` | `Create recruiter, networking, and interview versions of one positioning spine.` |

| `stories` | `Help me build a story about influencing without authority, one question at a time.` | `Audit my storybank for staff-level gaps and map the strongest stories to this role.` |

| `analyze` | `Analyze this transcript, score supported answers, and identify the primary bottleneck.` | `Review this incomplete panel transcript while preserving speaker and coverage uncertainty.` |
| `round` | `Capture my impressions first, then analyze this transcript and update the whole post-interview loop.` | `Run the full memory-only round workflow now and leave transcript scoring for later.` |
| `feedback` | `Record this written recruiter feedback and show what it changes in our coaching hypothesis.` | `We advanced despite a low practice score; update the outcome and check calibration.` |
| `progress` | `Review my progress across real interviews and choose the next two priorities.` | `Check whether scores predict outcomes or whether targeting and role fit explain the gap.` |
| `reflect` | `I accepted an offer; create a retrospective and help me decide what state to retain.` | `I am pausing this search - summarize durable learning without forcing a success narrative.` |
| `thankyou` | `Draft distinct thank-you notes for these two interviewers using real callbacks.` | `Write a concise follow-up after the hiring-manager round without over-correcting my answers.` |
| `salary` | `Prepare me for the recruiter's salary-expectations question tomorrow.` | `Build a sourced compensation range and scripts for pushback without revealing unnecessary current pay.` |
| `negotiate` | `Analyze this offer and build a prioritized ask ladder for base, equity, and flexibility.` | `Practice the offer call and flag the non-compete and equity questions for qualified review.` |

End the help response by asking which mode the user wants or inviting them to adapt one of the examples with their role, timeline, and materials.
