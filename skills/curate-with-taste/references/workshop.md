# Human-Led Workshop

Use this guide when the user wants to stay in the creative loop or asks for the complete better workflow.

## Operating rule

Move through Frame, Explore, Critique, Explore again, Select, and Refine. The sequence protects the user's decision-making role. It is not a requirement to make every response long or to produce a fixed number of options.

Maintain a compact working state in the conversation:

- Current frame and success evidence.
- Directions explored and how they differ.
- User reactions, selections, and rejections.
- Open uncertainties and the next decision.

Persist this state only when the user requests it and approves the destination.

## Frame

Resolve the artifact, audience, purpose, desired response, constraints, source material, reference signals, and the decision the user wants to own. Ask the single highest-value missing question when the frame would otherwise produce generic exploration. Record assumptions when a reasonable default allows progress.

Do not let the first generated idea become an accidental brief.

## Explore

Open the possibility space with materially different directions. Vary consequential dimensions such as premise, audience promise, structure, tone, mechanism, level of novelty, or emotional posture. Describe each direction clearly enough for the user to react without polishing every option into a finished artifact.

Avoid near-duplicate wording presented as separate concepts. Explain the defining decision and tradeoff of each direction.

## Critique

Use the creative frame and [the critique matrix](critique-matrix.md). Ask for the user's reaction before overriding it with analysis. Examine audience fit, underlying decisions, and craft quality. Identify what should survive into another exploration.

Critique the directions without converting the discussion into a universal quality ranking.

## Explore again

Use the critique as information. Produce directions that enter a genuinely different conceptual neighborhood or combine approved elements in a new way. A valid second exploration changes at least one major premise, structure, mechanism, audience promise, or emotional posture. Synonyms and cosmetic shifts do not qualify.

If the first exploration was already broad and the user has a clear preference, deepen the strongest unresolved direction instead of generating options for their own sake.

## Select

Pause for the user's decision. Summarize the meaningful tradeoffs and recommend a direction when useful, but identify the recommendation as advice.

If the user explicitly delegates selection, choose using the stated audience, purpose, constraints, feedback, and taste profile. Record the criteria and keep the choice reversible. Do not infer delegation from a request to “make it better.”

## Refine

Develop only the selected direction. Preserve the reason it was chosen while improving craft, resolving weaknesses, and meeting format constraints. For prose, use [the writing guide](writing.md) and run its strict final check.

Compare the final artifact with the frame and selected direction. If refinement exposes a material framing problem, surface it rather than quietly switching concepts.

## Fast paths and stopping conditions

The user may request a compact workshop in one response. In that case, show the frame, distinct directions, critique, and recommendation, then leave the selection explicit unless the user delegated it.

Finish when a direction has been selected, refined, and verified against the frame. Stop earlier when selection is required, the user must supply evidence, a permission is missing, or the available options reveal a framing decision only the user can make.
