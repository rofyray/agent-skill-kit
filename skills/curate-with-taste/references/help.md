# Curate with Taste Help

Use this reference to answer help mode. Present the explanation, complete mode catalog, start guidance, and examples in a detailed but scannable user-facing form. Include every named mode and both example columns. Do not inspect, draft, critique, or revise an artifact while answering help.

## What this skill does

This skill helps a user develop and apply taste while keeping creative decisions in human hands. It can inspect prose for formulaic AI defaults, create or rewrite writing with a stronger voice, compare creator and audience reactions, guide an iterative creative workshop, and build a reusable taste profile from real preferences and feedback.

It treats taste as context-dependent curation. It can recommend and explain, but the user remains the default owner of selection. It does not claim to detect whether AI authored a text.

## Modes

| Mode | Use it for |
| --- | --- |
| `inspect` | Review existing prose for formulaic patterns, weak voice, generic choices, and audience mismatch without rewriting unless requested. |
| `write` | Draft or rewrite prose while preserving meaning, facts, voice, and audience fit. |
| `critique` | Analyze one artifact or compare options through creator reaction, audience response, and craft. |
| `workshop` | Move through Frame, Explore, Critique, Explore again, Select, and Refine while keeping the user in the loop. |
| `calibrate` | Build or update a taste profile from examples, decisions, and audience feedback. |
| `help` | Display this guide without beginning another workflow. |

Modes are natural-language hints, not slash commands. The user can name one or simply describe the outcome.

## Start here

For `inspect` or `write`, provide the prose or topic and any important audience, purpose, voice, length, or factual constraints. For `critique`, provide the artifact or options plus what you and the intended audience seem to like or dislike. For `workshop`, describe what you are creating and the decision you need to make. For `calibrate`, share several liked and disliked examples or prior selections with brief reasons.

A rough starting point is enough. The skill asks only for missing context that would materially change the result. File reading, persistent profiles, and external publication depend on the active host's capabilities and user approval.

| `help` | `Help` | `Show every Curate with Taste mode and examples without reviewing anything yet.` |

End the help response by asking which mode the user wants or inviting them to adapt an example.
