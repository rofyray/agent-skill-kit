# Taste Profile

Use this guide to build or update a reusable model of the user's preferences. A taste profile is a working set of evidence-backed principles, not a permanent personality label.

## Gather useful evidence

Prefer multiple examples that reveal contrasts:

- Work the user likes and the decisions they value.
- Work the user dislikes and the reasons it fails for them.
- Options the user selected or rejected during workshops.
- Edits the user accepted, reversed, or repeatedly requested.
- Observed audience feedback and outcomes.
- Contexts where the same preference changes.

Ask “what about this works for you?” rather than inferring every preference from the artifact alone. Separate the user's reaction from the agent's interpretation.

## Extract decision-level principles

Translate examples into reusable choices such as directness, rhythm, density, specificity, novelty, warmth, visual hierarchy, pacing, or tolerance for ambiguity. Avoid copying phrases or reducing taste to a creator's name.

For each principle, record:

- The preference in decision-ready language.
- Scope, audience, or medium where it applies.
- Evidence from examples or user reports.
- Status as observed, reported, or inferred.
- Confidence as High, Medium, or Low.
- Known exceptions or tensions.

Keep preference separate from rule. “Usually prefers short openings in product updates” is more useful than “always write short openings.” Preserve contradictions until context explains them.

## Suggested compact profile

```markdown
# Taste Profile

## Scope and audience

## Preferences to preserve

## Defaults to avoid

## Context-dependent tensions

## Evidence and examples

## Open hypotheses
```

Keep the profile small enough to review before future work. Store locators or concise observations instead of copying large source artifacts.

## Apply and update the profile

Use the profile as a hypothesis before creation, not as a substitute for the current brief. During critique or selection, note where the user's decision confirms, narrows, contradicts, or retires a principle.

Audience feedback updates the model of audience response. It does not automatically replace the creator's preference. Record the divergence and the context in which it matters.

Before saving or changing a persistent profile, show the proposed principles and obtain approval for the destination. If persistence is unavailable, return a complete copyable profile and state that it is not synchronized across conversations.
